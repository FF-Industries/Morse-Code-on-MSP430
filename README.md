# Morse Code on MSP430

Code is designed to work on MSP430 chip with a PCB having 2 LEDS . The code simulates morse code using flashing LEDs to signify Dots and Dashes.
To furhter understand code please refer to the code exp.txt file. Download all files to run the code.
